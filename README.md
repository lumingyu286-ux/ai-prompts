# AI 提示词库

这里用于整理和分享我的 AI 提示词。每条提示词保存为一个 Markdown 文件，方便查找、修改和查看历史版本。

## 如何添加提示词

1. 打开 [prompts 文件夹](./prompts/)。
2. 点击 **Add file → Create new file**。
3. 文件名写成 `主题/提示词名称.md`，例如 `写作/文章大纲.md`。GitHub 会自动创建主题文件夹。
4. 复制[提示词模板](./prompts/提示词模板.md)，填入自己的内容，然后点击 **Commit changes** 保存。

也可以直接上传已有的 `.md` 或 `.txt` 文件。一个文件放一条提示词，标题尽量能说明用途。

## 建议的分类

按需要添加文件夹，例如 `写作/`、`编程/`、`学习/`、`工作/`。分类只是建议，可以按自己的习惯调整。

## 公开提醒

这个仓库是公开的。提交前，请删去 API Key、密码、客户资料、未公开文档和其他不想公开的信息。Git 历史会保留曾提交过的内容。
